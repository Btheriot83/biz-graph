I've managed over $200 million in ads on facebook/instagram and now I don't even physically log into ads manager, ai handles it for me yesterday claude code built an end to end lead gen campaign for me, here's how: 1) BROWSER USE business manager, where you configure your ad account, settings, upload assets etc., is a pain to use... I let claude code handle it through the chrome extension...it created a fresh pixel, created a system user token so it could programmatically manage the campaigns, link all the assets together and I didn't have to click one thing 2) CREATIVE I used scrapecreators to feed my ai inspo from direct to consumer ecom brands. they're the best at testing creative formats and angles so I always look there. I arrived at a super organic "job photo + text bubble" overlay that required no video editing or design tweaking...12 creatives complete in 15-20 minutes. I used my ads and direct response copy skills to ensure my positioning and angle were dialed for my icp 3) LANDING PAGE simple calendar booking flow with a "quiz funnel". this is an engaging page that helps you self qualify leads and creates micro commitment along the way. don't try to go right for the sale on meta, capture high intent leads and close via follow ups (phone, retargeting, sms, email, etc.) 4) TRACKING claude code grabbed the pixel and CAPI information from the browser session, implemented and tested the events. I remember hiring developers for this back in the day, no longer needed. now I can a) ensure my campaigns are optimized for the right event and b) measure results 5) BUILD claude code created a system user token and I securely stored it in the environment so that it could programmatically create the campaigns and launch them...there's an mcp too btw. the hang up most people face is asset access - more on this. 6) TARGETING none. I always go broad and let the meta machine optimize for the event I'm trying to achieve. please don't optimize for something like clicks or landing page views. go deep in the funnel for what you actually want. "but fb needs 50 conversions a week!" doesn't matter. 7) SKILL based on my work, I created a free public skill so that you too can have claude code or whatever agent you use setup your campaigns properly. from system access, token, what needs to be driven by UI vs API, testing events, etc. link in the replies. so far my campaign is generating leads for less than $2 per and is unlocking a major leverage point in my business. wish I would have had this available when I was manually managing 6 figs+ per day! enjoy...
